# System Requirements:

OpenBVE requires the following:

* Mono or the .Net framework.
* An OpenGL 4.3 supporting graphics card (GL1.2 is supported using the old renderer, but is not reccomended, and will be removed in a future release)
* An OpenAL supporting sound card.
* A minimum 2gb of RAM.
* Approximately 500mb upwards of disk space per route.
* Keyboard / mouse.

We also support various cab controllers- See:

<a href="https://openbve-project.net/play-cabcontrollers/">https://openbve-project.net/play-cabcontrollers/</a>
