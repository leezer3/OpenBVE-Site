### Significant Changes:
* New: Realtime sun / shadow preview in viewers. (Aditiya Afrizal)
* New: Improved shadow smoothing options. (Aditiya Afrizal)
* New: Add **TotalStates** **CarMass** **DecelerationMotor** and **RailNumber** animated instructions.
* Fix: Some HKHSS routes incorrectly detected as HMMSim.
* Fix: Interpolation issue in BVE5 routes where two legacy curve commands are within 25m.
* Fix: Unable to enable time acceleration when no train plugin loaded.
* Fix: Some touch controls broken by move to GL4.
* Fix: Copy + paste error in custom power beacons. (Aditiya Afrizal)
Fix: MP3 decoding not working on Linux. (Aditiya Afrizal)
* Change: Update OpenTK fork.
* Change: Update MP3 decoder implementation.
* Change: Fix some more issues with HMMSim routefiles.
* Change: Various performance improvements to route / object loading. (Aditiya Afrizal)
* Change: Significantly improve the memory usage / performance of animated GIF files. (Aditiya Afrizal)
* Change: Significant changes to the handling of semi-colons in the RW routefile format. Please see the following [errata note](https://github.com/leezer3/OpenBVE/wiki/Errata#rw-format)
* Change: When calculating exposed frontal area, the multiplier of 0.65 is now used for cars which do not specify a width / height. Please see the following [errata note](https://github.com/leezer3/OpenBVE/wiki/Errata#car-frontal-area-calculation)
* Compatability: Update routefile database.
* MSTS: Add accelerometer to handled CVF instructions.
* MSTS: Implement interior views for cars other than the driver car on MSTS stock.
