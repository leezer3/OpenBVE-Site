This release brings various improvements to the handling of BVE5 / BVE6 content. 
Whilst mostly minor, many routes should benefit from slightly better object placements.

### Significant Changes:
* Change: Improve the handling of BVE5 objects placed using a span. (Aditiya Afrizal)
* Change: ATS-EX content is now skipped when encountered in BVE5 / BVE6 files, rather than not loading the file at all.
* Change: Improve the crack distortion for some BVE5 / BVE6 content. (Aditiya Afrizal)
* Change: When BMP textures are used in BVE5 / BVE6 content, pure black is transparent.
* Change: Accept cant values in both mm and M for BVE5 / BVE6 content.
* Change: Where two **Interpolate** statements exist at the same track position, BVE5 / BVE6 take the first, rather than the second for all other cases.
* Change: Legacy curves in BVE5 no longer use interpolation.
* Fix: Improvements to X parsers, to handle some edge-case files.
* Fix: DDS parser failed to load some uncompressed RGB files. (Aditiya Afrizal)
* Fix: Issue with touch commands being passed to plugins.
* Fix: Check that the section attached to a transponder is valid when updating.
* Fix: Improve check for invalid section on orphaned transponders.
* Fix: More HKHOS content incorrectly detected as Hmmsim.
